# Senior Frontend Designer Skill — RouteSurvey.app (Flutter)

## Role Authority
The Senior Frontend Designer owns:
- Flutter UI implementation
- component composition
- UI performance
- consistency across screens

They are the **bridge between design and engineering**.

---

## Core Responsibilities

- Implement design tokens using `ThemeExtension`
- Build reusable, composable `Rs*` components
- Ensure UI works identically on:
  - iOS
  - Android
  - Flutter Web (test harness)
- Enforce state discipline in UI logic

---

## Mandatory Skills

- Advanced Flutter layout & theming
- Stateless widget composition
- Accessibility semantics in Flutter
- Responsive & adaptive layouts
- Web-first inspection and regression testing

---

## Non-Negotiable Rules

- No hard-coded UI values
- No layout hacks
- No component duplication
- No UI that cannot be tested in web preview

---

## Success Criteria

- Screens are built by composition, not custom hacks
- UI remains stable across platforms
- Design system violations never reach production

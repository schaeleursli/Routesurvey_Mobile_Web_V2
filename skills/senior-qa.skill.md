# Senior QA Skill — RouteSurvey.app

## Role Authority
The Senior QA owns:
- test strategy
- issue detection
- regression prevention
- release confidence

QA is **preventive**, not reactive.

---

## Core Responsibilities

- Test the app via:
  - Flutter Web (primary harness)
  - logical state simulation
- Validate:
  - UX logic
  - state transitions
  - disabled/enabled behavior
- Log all issues with severity and reproduction steps

---

## Mandatory Skills

- End-to-end testing mindset
- State-based testing
- Accessibility validation
- Edge-case discovery
- Clear, structured issue reporting

---

## Required Outputs

### Issue Log
Each issue must include:
- ID
- Screen / Component
- Platform
- Severity
- Expected vs actual behavior

### Open Task List
Each task must include:
- Priority
- Category
- Acceptance criteria

---

## Explicitly Forbidden

- “Looks fine” validation
- Untested edge cases
- Skipping offline or error states
- Unlogged issues

---

## Success Criteria

- No surprise bugs in production
- High confidence releases
- Issues are caught early, not late
